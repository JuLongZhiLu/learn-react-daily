# learn-react-daily
我想通过每天学习一个React的小知识来逐渐掌握React。

这并不是一个严谨的项目，可能会有很多错误，因为其中记录的大部分内容只是我和AI的对话。

不过随着我对React的掌握加深，我可能会回过头来修改之前的内容。

----
这是个很好的思路。

很多人学 React 失败，不是因为 React 难，而是因为一开始就试图：

* 学完 JSX
* 学完组件
* 学完 Hooks
* 学完 Redux
* 学完 Router
* 学完 TypeScript
* 学完 Next.js

结果信息量过大，坚持不下来。

而「每天一个 React 小知识」实际上更符合长期学习规律。
